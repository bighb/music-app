边界演练:
1. 边界状态设计规范与容灾表现 (Edge Cases & Resilience Spec) 离线脱网、未搜到、弱网解析与异常
边界场景 视觉触发与形态设计 自愈操作与交互流
断网离线 (Offline Mode) 在搜索框下方滑出优雅黄色提示条：[离线模式] 网络未连接，仅展示与播放本地已下载内容；信号栏切换断网图标；仅本地歌曲保留高亮可播，未下载歌曲置灰。 提供行内「重试连接」快捷触发；恢复网络后提示条平滑收起。
未搜索到 (Empty Search) 搜索输入无匹配时，静默切换为极简居中状态：带暗色搜索图标、主标题「未找到相关歌曲」、说明「可尝试歌手全名或直接粘贴链接」。 提供纯净线框按钮「清空输入」，点击后清空关键词并恢复全量流。彻底废除干扰性弹框提示。
网络异常 / 302 超时 (Network Error) 音源跨协议重定向超时或网络震荡时，列表区展示红色微弱衬底卡片，明确指出「网络连接超时，无法解析在线音源」。 提供「重新尝试」主按钮与「查看诊断日志」链接，杜绝静默失败。
解析缓冲中 (Buffering State) 解析多源音轨时，展示单色 2px 极细 Accent 环形微动画 +「正在匹配最佳音源...」。 非阻塞式呈现，解析完成后平滑过渡到播放页。

5. 酷狗音乐经典播放风格规范 (Kugou Visual Playback Spec) 破格黑胶浮岛、环形进度播放键、封面流光高斯模糊与炫胶唱盘
酷狗经典视觉要素 形态构造与交互细节 Compose 技术落地映射
破格悬浮黑胶 (Breaking-out Disc) 底部迷你播放条左侧唱片向上破格突破外框（外溢 12px），平滑匀速旋转，赋予界面极强的实体唱机感。 在 Compose 中使用 offset(y = (-8).dp) 配合 clip(CircleShape) 与旋转动画。
环形进度播放键 (Circular Progress Ring) 废除单调的横条进度，将播放进度直接化为**围绕播放/暂停圆钮的环形走字弧线（SVG Ring）**，顺时针闭合，兼顾极简与辨识度。 使用 CircularProgressIndicator(progress = { ... }, strokeWidth = 2.5.dp) 将 IconButton 居中包裹。
全屏封面流光模糊 (Adaptive Ambient Blur) 彻底告别冰冷死黑，提取正在播放的歌曲封面色，叠加超大半径高斯模糊（Blur 48px）与暗角渐变，营造温暖沉浸视听氛围。 全屏播放页底层采用 AsyncImage + blur(50.dp) + radialGradient(vignette)，配合弱光呼吸动效。
炫胶唱盘与金属唱针 (Vinyl & Tonearm) 高精黑胶唱纹、外沿氛围微光、机械金属唱针在播放时物理落针、暂停抬起。 基于 rotate(angle) 驱动唱针，黑胶转盘施加 elevation = 24.dp 深度投影。
Hi-Res 金标与蝰蛇微标 (Audio Badges) 歌名下方配备酷狗标志性金标 [Hi-Res] 与 [蝰蛇全景声]，传达专业音质心智。 极简紧凑微标胶囊组件，统一字号与视觉层级。
5. 播放组件层级投影规范 (Elevation & Drop-Glow Shadows) 通过多层物理光影拉开空间景深，强化悬浮突出感
核心播放组件 形态与投影构造 (Elevation & Shadow Tokens) Compose 技术实现规范
底部悬浮播放条 (MiniPlayerBar) 独立浮岛胶囊形态 (Floating Dock)。悬浮于底导航之上，四周留白（左右各 10px，下距 64px）；双层物理投影：底黑深层散焦影 0 14px 34px -4px rgba(0,0,0,0.88) + 顶层微弱电光紫氛围微晕 0 6px 20px rgba(124,58,237,0.32) + 顶部 1px 微反光描边。 Modifier.shadow(elevation = 12.dp, shape = RoundedCornerShape(16.dp), ambientColor = Color.Black, spotColor = Color(0x7C3AED).copy(alpha = 0.35f)) + border(1.dp, Color(0x7C3AED).copy(alpha = 0.35f))。
全屏主播放控制键 (Main Play Button) 全屏能量焦点 (Energy Core)。68dp 实心电光紫渐变大圆钮；配置专属高扩散立体辉光阴影：0 12px 30px rgba(124,58,237,0.58) + 底部环境黑影 0 4px 10px rgba(0,0,0,0.5)；按压物理缩放回弹反馈。 使用带弥散投影的 Box 或自定义绘图修饰符 drawBehind 绘制径向渐变阴影，突出全屏唯一的核心操作抓手。
黑胶唱片转盘 (Vinyl Record 3D) 立体悬浮景深 (Floating Disc)。254dp 径向黑胶槽纹；叠加 0 26px 56px rgba(0,0,0,0.92) 重度深空落影 + 0 0 40px rgba(124,58,237,0.22) 周边泛光，拉开唱片与背景的悬空距离。 Compose 中对黑胶转盘容器施加 elevation = 24.dp，配合中心高光圆环形成硬件实体感。
正在播放条目 (Active Track) 微抬升浮层 (Elevation 2dp)。列表与队列中的当前播放歌曲，卡片轻微上浮 1px，赋予 0 4px 16px rgba(124,58,237,0.20) 柔和紫光衬底。 Card(elevation = CardDefaults.cardElevation(defaultElevation = 2.dp))。
4. 「我的」三 Tab 手势横滑切换规范 (HorizontalPager Gesture Spec) 收藏 / 离线 / 历史 支持左右滑动跟手切换
规范维度 视觉与交互表现 Compose 技术实现约束
手势跟手性 (Swipe Gesture) 在内容列表区域左右拖动手势时，3 个 Tab 内容（收藏、离线、历史）跟随手指位移无缝平移；位移超过 25% 宽度或滑动速度足够时自动吸附切换至相邻 Tab，未达阈值平滑弹回。 采用 HorizontalPager(state = pagerState) 承载；在 FavoritesScreen.kt 中剥离原静态 when (selectedSubTab)，实现与 TabRow 双向绑定。
Tab 联动指示 (TabRow Sync) 手势滑动时，上方 Segmented Tab 的高亮指示块随 Pager 滚动进度实时插值平移，保证滑到哪、高亮到哪，松手即就位。 使用 rememberCoroutineScope 在点击 Tab 时调用 pagerState.animateScrollToPage(index)；监听 pagerState.currentPage 回调 onSubTabChange。
滚动冲突隔离 (Scroll Disambiguation) 垂直滑动（上下浏览歌曲列表）由内部 LazyColumn 优先消费；仅在横向拖动夹角主导时触发 Pager 水平翻页，无任何手势打架或卡顿。 Compose 内置嵌套滑动调度机制（NestedScrollConnection），原生支持垂直 LazyColumn 与水平 HorizontalPager 完美互锁。
3. 播放队列交互与功能待办 (Playback Queue & Reorder Spec · Issue #6) 当前播放固定首位，待播放列表长按自由拖拽调序
队列层级 定位与交互行为 代码实现约束 (Compose / State)
当前播放曲目 (Index 0) 永久置顶固定 (Pinned at top)。无论如何拖动后续待播列表，当前播放项始终处于队列第 1 位。无拖拽手柄、不响应长按位移、不可被跨越或置换。 在 PlaylistBottomSheet.kt 中剥离拖拽修饰符；onReorderQueue 拦截任何 toIndex == 0 或 fromIndex == 0 的越界请求。
待播放曲目 (Index >= 1) 长按拖拽排序 (Drag-to-Reorder)。右侧提供极简抓手图标（⋮⋮），长按任一待播项即可触发平滑上下拖拽位移；松手立即生效并保存待播顺序。 废除原笨重的上下箭头图标 (KeyboardArrowUp/Down)；采用 Compose detectDragGesturesAfterLongPress 或 ReorderableLazyColumn，触发 HapticFeedbackType.LongPress 触感振动。
拖拽视觉反馈 (Drag Feedback) 被抓取项浮起（Z轴提升 + 轻微暗度高亮 + 虚线外框），相邻项自动平顺推开避让，提供确定性的落位指示。 仅更新待播列表内存副本与 PlayerState.playlist，确保后台 ExoPlayer / MediaSession 待播缓冲无缝同步。
